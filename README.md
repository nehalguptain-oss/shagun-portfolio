# Shagun Kumari — Portfolio
Responsive single-page portfolio made with HTML, CSS, and vanilla JavaScript. No build tools or backend are required.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling
- `script.js` — mobile navigation, reveal animations, current year
- `assets/` — place the approved profile photo here

## Add a photo
Save it as `assets/shagun-photo.jpg`. In `index.html`, uncomment the `<img src="assets/shagun-photo.jpg" alt="Portrait of Shagun Kumari">` line and remove the placeholder `<div class="placeholder">...</div>`.

## Publish
1. Create a public GitHub repository, e.g. `shagun-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and `assets/` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After deployment, the URL will look like `https://YOUR-USERNAME.github.io/shagun-portfolio/`.

Verify the email and LinkedIn details before publishing. Only use a photo Shagun has approved for public display.
